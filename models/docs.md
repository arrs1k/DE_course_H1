# Аналитический слой интернет-магазина

Этот проект собирает аналитический слой (схема «звезда») в хранилище Greenplum на основе сырых данных OLTP-базы магазина. 
Включает в себя факты заказов, позиций и измерения клиентов, товаров (с иерархией категорий) и календарь.
